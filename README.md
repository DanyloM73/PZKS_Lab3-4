# Лабораторні роботи №3–4 з дисципліни «Програмне забезпечення комп’ютерних систем»

Консольна програма мовою Kotlin, що визначає множини еквівалентних форм арифметичного виразу за комутативним і дистрибутивним законами. Вона перевіряє вираз лексичним і синтаксичним аналізатором із лабораторної роботи №1 та семантичною перевіркою з лабораторної роботи №2, будує для кожної отриманої форми дерево паралельної форми й обирає форму з мінімальною кількістю ярусів. Режим побудови паралельної форми з лабораторної роботи №2 також збережено.

## Системні вимоги

- 64-бітна операційна система Windows, macOS або Linux;
- Java 21 або новіша версія;

## Завантаження

1. Відкрийте [останній реліз програми](https://github.com/DanyloM73/PZKS_Lab3-4/releases/latest).
2. У розділі **Assets** завантажте файл `PZKS_Lab3-4-1.0.0.zip` та розпакуйте його.
3. Виконайте інструкцію для своєї операційної системи.

## Встановлення та запуск у Windows

Відкрийте PowerShell і запустіть програму:

```powershell
& "$HOME\Downloads\PZKS_Lab3-4-1.0.0\bin\PZKS_Lab3-4.bat"
```

Якщо програма знаходиться в іншій папці, замініть шлях у команді на фактичний.

## Встановлення та запуск у macOS і Linux

Відкрийте термінал і перейдіть до папки програми:

```bash
cd ~/Downloads/PZKS_Lab3-4-1.0.0
```

Надайте файлу дозвіл на виконання (якщо потрібно):

```bash
chmod +x bin/PZKS_Lab3-4
```

Запустіть програму:

```bash
./bin/PZKS_Lab3-4
```

## Використання

Програма має три режими роботи:

- `:parallel` (`:par`) — побудова паралельної форми виразу (лабораторна робота №2);
- `:commutative` (`:comm`) — еквівалентні форми за комутативним законом (лабораторна робота №3);
- `:distributive` (`:dist`) — еквівалентні форми за дистрибутивним законом (лабораторна робота №4).

Після запуску програма працює в режимі паралельної форми. Щоб перейти до іншого режиму, введіть його команду, а потім арифметичний вираз і натисніть Enter:

```text
:comm
a + b*c + d
```

Режим можна також задати під час запуску параметром `--mode`, наприклад `--mode=commutative` або `--mode=dist`. Якщо після параметра вказати вираз, програма обробить його й завершить роботу:

```bash
./bin/PZKS_Lab3-4 --mode=dist "a*b + a*c + b*c + a*d"
```

У режимах комутативного та дистрибутивного законів для коректного виразу програма виводить:

- вихідну форму виразу;
- групи операндів, які можна переставляти, та кількість їхніх перестановок (для комутативного закону);
- загальну кількість еквівалентних форм;
- таблицю форм із кількістю ярусів, операцій і найбільшою кількістю одночасних операцій для кожної форми;
- для дистрибутивного закону — номер форми, з якої отримано кожну форму, застосоване правило та перетворений фрагмент;
- розподіл форм за кількістю ярусів;
- найкращу форму та її порівняння з вихідною;
- дерево паралельної форми найкращої форми у вигляді таблиці за ярусами та розклад виконання операцій.

Для комутативного закону оцінюється не більше 50 000 форм, але загальна кількість форм обчислюється точно, а форма з мінімальною кількістю ярусів завжди потрапляє до результатів завдяки сортуванню термів за вагою. Для дистрибутивного закону перебір обмежено 500 формами.

У режимі паралельної форми програма, як і в лабораторній роботі №2, виводить покрокову оптимізацію, паралельну форму виразу, кількість операцій, ярусів і найбільшу кількість одночасних операцій до та після оптимізації, дерево паралельної форми та розклад виконання.

Якщо вираз містить лексичні чи синтаксичні помилки, ділення на нуль або недопустимі аргументи функцій, програма показує тип і точне місце кожної помилки у введеному виразі.

Програма підтримує:

- числа та змінні;
- оператори `+`, `-`, `*`, `/`;
- унарні оператори `+` і `-`;
- круглі дужки;
- функції `sin`, `cos`, `tan`, `ctg`, `sqrt`, `abs`, `round`, `ln`, `log10`, `pow`, `min` і `max`.

Додаткові команди:

- `:tree N` — показати дерево паралельної форми та розклад виконання для форми з номером N;
- `:all` — показати всі отримані форми;
- `:functions` — показати перелік доступних функцій;
- `:exit` — завершити роботу програми.
